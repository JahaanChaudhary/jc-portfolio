Featured Project

RakhtSathi

Blood requests in emergencies fail because there's no fast way to find compatible donors nearby. RakhtSathi matches recipients to donors across 8 blood groups using geolocation search and Haversine-distance ranking — production-deployed and live. Three role-based flows secured with Spring Security + BCrypt, OTP email verification, and async bulk-email notifications. Resolved a tricky circular dependency in Spring Security config by extracting BCryptPasswordEncoder into its own @Configuration class.

  • Spring Boot
  • PostgreSQL

  • JPA/Hibernate
  • Thymeleaf
  • Leaflet.js
